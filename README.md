# משחקי רומי

משחקי למידה בעברית לילדים: חשבון חזותי, היגיון, קריאת שעון וקריאה.

## הפעלה

פתחו את `index.html` בדפדפן. יש לשמור לצדו את `learning.js`. אין שרת, התקנה או שירות חיצוני. אפשר גם לשרת את התיקייה בשרת קבצים סטטיים מקומי. שמירת התקדמות בקובץ מקומי עשויה להשתנות בין דפדפנים; לאימות שמירה עדיף שרת מקומי.

## גרסת ניסוי: בסיס למידה

- מסך בית, ולאחריו פעילות אחת. חשבון והיגיון מוצגים ראשונים.
- סימון חפצים כדי להימנע מספירה כפולה, ורמזים לימודיים בחשבון.
- כוכבים מתגמלים התמדה גם אחרי תיקון. בנפרד, מפת 13 מיומנויות מתעדת את חמש התוצאות האחרונות בכל מיומנות. הצלחה עצמאית היא השלמה בלי טעות ובלי רמז באתגר.
- 4 מתוך 5 הצלחות עצמאיות הן כלל ניסוי שקוף לתיאור התרגול, לא אבחון, הבטחת למידה או שליטה מוכחת. כוכבים עדיין מאפשרים מעבר רמת תרגול, לא הסמכת מיומנות.
- הנתונים נשמרים ב־localStorage במכשיר בלבד: כוכבים, רמות נבחרות וסיכומי מיומנויות. אין שם ילד, חשבון, אירועים מפורטים או תקשורת לרשת. מחיקת נתוני דפדפן מוחקת את ההתקדמות. כשל בשמירה אינו חוסם משחק.
- הקראה משתמשת בקול העברי שהדפדפן/מערכת ההפעלה מציעים. אין הבטחה לקול עברי או להקראה offline בכל מכשיר. לא נבדק על מכשירים פיזיים.

## בדיקות

בדיקות לוגיקה, ללא תלויות:

```sh
node --test learning.test.cjs
```

בדיקת דפדפן מקומית (פיתוח בלבד):

```sh
npm install --no-save --package-lock=false playwright-core
node browser.test.cjs
```

הבדיקה משתמשת ב־Chrome מותקן ב־`/usr/bin/google-chrome` ובשרת מקומי זמני בלבד. היא אינה מוסיפה תלויות runtime למשחק. יש לבצע גם בדיקות ידניות ב־Safari/iOS, Chrome/Android וטאבלט לפני פיילוט.

## עדיין לא מוכן להשקה

נדרשים צפייה בילדים בהסכמת ההורים, בדיקת התוכן בידי אשת חינוך, בדיקות מכשירים/קול/נגישות, ובדיקת יכולת לפתור שאלה חדשה ולא רק לאסוף כוכבים. אין אפליקציות חנות, חשבונות ילדים, תשלום, פרסומות, צ'אט או ענן. אין כאן טענה קלינית או מדעית ליעילות.

הבסיס המקורי נבנה עם Muse, אוקטובר 2026.
